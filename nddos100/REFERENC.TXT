=====================================================================
【NEWDELY_INSTANCE】    インスタンス・グローバル・ポインタ
---------------------------------------------------------------------
    構文: NEWDELY_INSTANCE

    処理: インスタンス・グローバル・ポインタを宣言する

    注意: #include "NewDely.h" の後に記述して下さい。
          分割コンパイルされる場合には、どれか１つのファイルにだけあれ
          よい。


=====================================================================
【NEWDELY_INITIAL】    インスタンス生成
---------------------------------------------------------------------
    構文: NEWDELY_INITIAL( errFunc );

    引数: int   (*errFunc)(int);  致命的エラー発生時に呼び出される関数
                                  へのポインタ
                                  =NULL: NewDelyエラールーチンに任せる

    戻値: void

    処理: インスタンス生成

    備考: errFuncをセットすることにより、エラー発生時の処理ができます。
          また、new の戻値をチェックする必要がなくなります。
          つまり、errFuncが呼び出されない限り、正しいメモリブロックが
          確保されたと考えられます。
          o errFunc()の例は、サンプルリスト "nd_mix.c" などをご参照下さい。
          o errFunc()の引数として与えられるエラー番号は以下のとおりです。
                 0: DOS Function ERROR
                 1: Out of memory.
                 2: 引数エラー
                 3: メモリブロック周辺が破壊されています
                 4: 引数：不適当なブロックサイズです
                 5: 初期化されていません
                 6: ページヘッダが破壊されています
                 7: メモリ･リーク（解放忘れ）発生しています
                 8: _dCheck エラー発生
                 9: 既に初期化されています
                10: 不正なポインタです
                11: 既に解放されたポインタです

    注意: 最初に必ず呼び出して下さい。


=====================================================================
【new】      メモリブロックの確保         標準new同様にお使いください
---------------------------------------------------------------------
    構文: lptr = new char[ size ];

    引数: WORD       size;  要求するメモリブロックのサイズ(byte)
                            範囲:[ 1～65,500 ]
                            約2,000byte以下の場合に最高のパフォーマンス
                            を発揮します。

    戻値: LPVOID     lptr;  ＦＡＲポインタ(32bit)

    処理: 指定されたサイズのメモリブロックを確保し、そのＦＡＲポインタ
          を返します。

    備考: 戻値を確認する必要はありません。
    　　　万一確保できなかった場合には、NEWDELY_INITIAL()により設定され
          たエラーハンドラを呼び出します。


=====================================================================
【delete】     メモリブロックの解放    標準delete同様にお使いください
---------------------------------------------------------------------
    構文: delete  lptr;

    引数: LPVOID     lptr;  ＦＡＲポインタ(32bit)   new の戻値

    戻値: void

    処理: メモリブロックを解放します。
          解放されたメモリブロックは、未使用のメモリとして再利用され
          ます。


=====================================================================
【NEWDELY_CHECK】    各種の診断をします
---------------------------------------------------------------------
    構文: NEWDELY_CHECK( mode );

    引数: int        mode;  =0: オーバーライトを診断する
                            =1: メモリリークについて診断します。
                                すべてのメモリブロックが解放されている
                                かを確認できます。

    戻値: int        iRet;  ==0: OK
                            !=0: ERROR

    処理: 各ページ内のヘッダとすべてのメモリブロックに付加されたチェッ
　　　　  クコードを調べます。
          オーバーライトしていそうな、行の直後に挿入すれば、バグの早
          期発見が可能です。

    備考: デバッグモード /D_AP_DEBUG の時だけ有効になります。
          リリースモードでは負荷はありません。

【ＳＫＥＬＥＴＯＮ】
---------------------------------------------------------------------
o 最小限の行だけを抜き出してあります。

#include "NewDely.h"      // (1)ヘッダファイル   
NEWDELY_INSTANCE          // (2)インスタンス・グローバル・ポインタ
                          //    どこかに１つだけあればよい

// (3)エラーハンドラ 
int errHandler( int iNo )
{
	switch( iNo )
	{
		case 0: puts("致命的エラーです");
				break;
		case 1: puts("ヒープメモリ・オーバーです");
				break;
	}
	return(0);  /* 強制終了 */
}

// オリジナル・クラス定義 
class Obj : public NewDely      // (4)NewDely より導出 
{
	int   iNo;
public:
	Obj(){ iNo = 0; }
	Obj( int i ){ iNo = i; }
	int GetNo(){ return iNo; }
};

// メイン 
void main()
{
	NEWDELY_INITIAL( errHandler );  // (5)インスタンス生成 
	
	Obj*  o = new Obj(3);              // オブジェクトの生成
	
	printf("size=%u.\n", o->size() );  // サイズを取得する
	
	NEWDELY_CHECK(0);                  // オーバーライト・チェック 
	
	delete  o;                         // オブジェクトの消滅
	
	NEWDELY_CHECK(1);                  // リーク・チェック 
	
	exit(0);
}
