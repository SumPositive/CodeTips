【_dAlloc】      メモリブロックの確保    malloc同様にお使いください。
---------------------------------------------------------------------
    構文: lptr = _dAlloc( size );

    引数: WORD       size;  要求するメモリブロックのサイズ(byte)
                            範囲:[ 1～65,524 ]
                            約2,000byte以下の場合に最高のパフォーマンス
                            を発揮します。

    戻値: LPVOID     lptr;  ＦＡＲポインタ(32bit)

    処理: 指定されたサイズのメモリブロックを確保し、そのＦＡＲポインタ
          を返します。

    備考: 戻値を確認する必要はありません。
    　　　万一確保できなかった場合には、_dInit()により設定された
          エラーハンドラを呼び出します。


=====================================================================
【_dCheck】      各種の診断をします
---------------------------------------------------------------------
    構文: iRet = _dCheck( mode );

    引数: int        mode;  =0: オーバーライトを診断する
                            =1: メモリリークについて診断します。
                                すべてのメモリブロックが解放されている
                                かを確認できます。

    戻値: int        iRet;  ==0: OK
                            !=0: ERROR

    処理: 各ページ内のヘッダとすべてのメモリブロックに付加されたチェッ
　　　　  クコードを調べます。
          オーバーライトしていそうな、行の直後に挿入すれば、バグの早
          期発見が可能です。

    備考: デバッグモード /D_AP_DEBUG の時だけ有効になります。
          リリースモードでの負荷はありません。


=====================================================================
【_dFree】       メモリブロックの解放
---------------------------------------------------------------------
    構文: _dFree( lptr );

    引数: LPVOID     lptr;  ＦＡＲポインタ(32bit)
                            _dAlloc の戻値

    戻値: void

    処理: メモリブロックを解放します。
          解放されたメモリブロックは、未使用のメモリとして再利用され
          ます。


=====================================================================
【_dInit】       ＤｏｓＡｌｌｏｃ初期化
---------------------------------------------------------------------
    構文: iRet = _dInit( errFunc );

    引数: int   (*errFunc)(int);  致命的エラー発生時に呼び出される関数
                                  へのポインタ
                                  =NULL: DosAllocエラールーチンに任せる

    戻値: int        iRet;  ==0: OK
                            !=0: ERROR

    処理: ＤｏｓＡｌｌｏｃの使用準備をします。

    備考: errFuncをセットすることにより、エラー発生時の処理ができます。
          また、_dAllocの戻値をチェックする必要がなくなります。
          つまり、errFuncが呼び出されない限り、正しいメモリブロックが
          確保されたと考えられます。
          o errFunc()の例は、サンプルリスト "da_mix.c" などをご参照下さい。
          o errFunc()の引数として与えられるエラー番号は以下のとおりです。
                 0: DOS Function ERROR
                 1: Out of memory.
                 2: 引数エラー
                 3: メモリブロック周辺が破壊されています
                 4: 引数：不適当なブロックサイズです
                 5: 初期化されていません
                 6: ページヘッダが破壊されています
                 7: メモリ･リーク（解放忘れ）発生しています
                 8: _dCheck エラー発生
                 9: _dRealloc サイズ変更できませんでした
                10: 不正なポインタです
                11: 既に解放されたポインタです

    注意: 最初に必ず呼び出して下さい。


=====================================================================
【_dRealloc】    メモリブロックのサイズ変更
---------------------------------------------------------------------
    構文: lpNew = _dRealloc( lpOld, size );

    引数: LPVOID    lpOld;  ＦＡＲポインタ(32bit)
          WORD       size;  >0: 新たなメモリブロックのサイズ(byte)

    戻値: LPVOID    lpNew;  変更後のＦＡＲポインタ(32bit)

    処理: lpOldで示されるメモリブロックを、新たなサイズで確保されたメ
          モリブロックへ移動し、lpOldを破棄します。
          そして、新たなメモリブロックへのポインタが、lpNewとして返さ
          れます。
          メモリブロックの内容は、新たなメモリブロックへコピーされます
          が、小さくなった場合には、末尾部分より欠けることになります。


=====================================================================
【_dSize】       メモリブロックのサイズを取得する
---------------------------------------------------------------------
    構文: size = _dSize( lptr );

    引数: LPVOID     lptr;  ＦＡＲポインタ(32bit)

    戻値: WORD       size;  !=0: サイズ(byte)
                            ==0: 無効なポインタです

    処理: lptrで示されるメモリブロックのサイズを返します。


=====================================================================
【_dTerm】       ＤｏｓＡｌｌｏｃの終了
---------------------------------------------------------------------
    構文: _dTerm();

    引数: void

    戻値: void

    処理: ＤｏｓＡｌｌｏｃの後始末を行います。
    　　　最後に必ず呼び出して下さい。

    備考: デバッグ･モードでは、リーク（解放忘れ）の診断と報告が行われ
          ます。

    注意: ＵＭＢやＨＭＡを利用している場合、_dTerm()が呼び出される以前
          にアプリケーションが異常終了すれば、ＤＯＳを再起動（リセット）
          する必要があります。　リセットせずに、アプリケーションを再起動
          すれば、ＵＭＢやＨＭＡが利用できない場合があります。
          ただし、エラーハンドラが起動されて異常終了した場合は、内部で
          _dTerm()処理が行われていますので、特別のメッセージが無い限り
          リセットする必要はありません。

【ＳＫＥＬＥＴＯＮ】
---------------------------------------------------------------------
o 最小限の行だけを抜き出してあります。

#include "DosAlloc.h"


int errHandler( int iNo )
{
	switch( iNo )
	{
		case 0: puts("_d: 致命的エラーです");
				break;
		case 1: puts("_d: ヒープメモリ・オーバーです");
				break;
	}
	return(0);  /* 強制終了 */
}


void main()
{
	LPVOID  lpv;
	
	if( _dInit( errHandler ) != 0 ) exit(-1);
	
	lpv = _dAlloc( 32 );
	
	printf("size=%u.\n", _dSize( lpv ) );    /* size=32. */
	
	lpv = _dRealloc( lpv, 64 );
	
	printf("size=%u.\n", _dSize( lpv ) );    /* size=64. */
	
	_dFree( lpv );
	
	_dTerm();
	
	exit(0);
}
